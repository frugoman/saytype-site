Getting started

Open SayType and follow the setup window. It asks for Microphone and Accessibility access and downloads the speech model (about 630 MB, one time). Then click into any text field and talk. When you pause, the text is typed.

SayType isn't in the Accessibility list

Open System Settings → Privacy & Security → Accessibility, click + below the list, choose Applications → SayType, and turn it on.

It doesn't type in a particular app

Some apps don't tell macOS where their text fields are. In SayType's Settings → General, add the app to Always listen in these apps.

It gets a word wrong

Open Settings → Vocabulary, add the word, and click Teach. Say the word three times, and SayType learns how it's misheard and fixes it from then on.

Shortcuts

  • ⌃⌥D turns dictation on or off
  • ⌃⌥S reads the selected text aloud (press again to stop)
